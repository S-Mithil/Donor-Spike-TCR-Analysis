# TCRβ repertoire analysis

This repository contains the custom R code used for TCRβ repertoire analyses in the study:

"Acute Allograft Rejection after SARS-CoV-2 Vaccination Associated with Expansion of Cross-Reactive Anti-donor and Spike-Reactive CD8 T-Cell Clones"

The annotated R script includes analyses for:
- donor-reactive and spike-reactive clonotype identification
- MLR–spike pairwise overlap analyses
- cumulative productive-frequency calculations
- longitudinal alluvial visualization
- biopsy clonotype-class analysis
- clonotype abundance ranking

The corresponding TCRβ sequencing data are available through ImmuneACCESS:
https://clients.adaptivebiotech.com/pub/soni-2026-s

Analyses were performed in R version 4.3.1.
